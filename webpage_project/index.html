Face-Tracking Camera Mount: Instructions

James Atzberger*,
Project@Home
Code Supplementary

Face-tracking and Camera Movements.

Abstract

We show how to build your very own face-tracking camera. We give instructions on how to design and 3d print the mount. We also show how to program the face-tracking. We list the type of camera, servo, and the other parts.

We hope you enjoy!

Face-Tracking Camera Mount: Our camera mount that moves by tracking your face to keep the camera pointed at you.

Instructions

    CAD / 3D Print Models and Assembling:

    We provide the source .stl files for 3D printing the camera mount and how to put them together below. All files can be downloaded from the project github.

    This shows the fully assembled mount.

    Details

    • We first create a base large enough to comfortably store your raspberry pi. This includes a way for the air to flow freely to help avoid overheating.

    • Next we make a cover to put over the base with a servo mount on top. This will be used to pan the camera left and right. This also includes a hole to connect the servos and camera to the raspberry pi.

    • We create a servo mount for tilting the camera up and down. We put a hole at the bottom (not visible) so a servo horn can be used to attach the pan-servo.

    • We make a mount for the camera to be attached to the tilting servo. This again uses a servo horn.

    • These parts are assembled to obtain the full mount.


    Programming:

    We give a brief explaination of the implementation and how different parts of the codes work.

    • Library imports

      • OpenCv: We will use open cv to handle image processing and face detection.

      • PigPio: Used as a substitute to the standard Pulse Width Modulation (PWM) library to reduce servo jittering.

      • OS: Will be used for file verification to avoid the program crashing during initialization.

    • Check that `pigpio` was successfully initialized

      • Checks that the background daemon called ‘pigpiod’ is running in order to control the servos.

    • Define and set the pan and tilt servo’s GPIO numbers.

    • Define variables to set the pan and tilt servos starting positions, range of motions, and increment values when rotating to center the detected face.

    • Define functions to control the servo in increments towards the desired direction.

    • Set servos to the starting position before scanning for faces.

    • Check and set the cascade path and classifier to where the OpenCv library stores pre-trained haar cascades.

    • Initialize the primary camera used for detecting the faces (0 means its the only external camera connected, you might need to choose a different number depending on your devices. For better performance, we down-scale the resolution and compress the stream.

    • Grab the current stream of the camera and throttle the facial detection to every 3 or more frames to limit compute power and help with performance.

    • Pre-process the current frame by calculating the center, dead-zones, and converting it to gray-scale for higher performance and easier reading.

    • Scan each grey-scale frame for any faces and get their coordinates.

    • Pan and tilt the camera to center the face in the frame based on its current position.

    • This safely shuts down the servos and camera.
